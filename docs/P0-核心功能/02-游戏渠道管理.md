# P0-02 游戏渠道管理

> 子需求ID：P0-02  
> 优先级：P0  
> 状态：待开发  
> 依赖：P0-01 计划组基础管理  
> 被依赖：P0-04 质检执行引擎

---

## 一、需求概述

### 1.1 功能简介

管理计划组下关联的游戏+渠道组合，支持独立启停控制。每个计划组可关联多个游戏渠道，实现批量质检管理。

### 1.2 业务价值

- 灵活配置质检覆盖范围
- 支持按游戏渠道独立控制质检开关
- 便于问题定位和异常处理

---

## 二、功能详情

### 2.1 游戏渠道配置操作

| 操作 | 入口 | 说明 | 交互细节 |
|------|------|------|----------|
| 添加 | 计划组展开后"添加"按钮 | 弹窗选择游戏→渠道（联动） | 游戏选择后渠道列表联动更新 |
| 移除 | 游戏渠道行操作菜单"移除" | 从计划组中移除该游戏渠道 | 需二次确认 |
| 启用/停用 | 游戏渠道行Switch开关 | 独立控制该游戏渠道是否参与质检 | 无需二次确认，即时生效 |

### 2.2 添加游戏渠道弹窗

**弹窗字段：**

| 字段名称 | 类型 | 必填 | 说明 |
|----------|------|------|------|
| 选择游戏 | 下拉选择 | ✅ | 从已配置的游戏列表中选择 |
| 选择渠道 | 多选复选框 | ✅ | 根据选中游戏显示可用渠道，支持多选 |

**交互逻辑：**
- 选择游戏后，渠道列表联动更新
- 已添加的游戏渠道组合置灰不可重复选择
- 支持批量添加（一个游戏多个渠道）

### 2.3 游戏渠道列表展示

**列表字段：**

| 字段名称 | 说明 | 展示要求 | 案例 |
|----------|------|----------|------|
| 游戏 | 游戏名称 | 文本 | 穿越火线 |
| 渠道 | 渠道名称 | 文本 | 微信 |
| 状态 | 当前质检状态 | 彩色状态标签 | 🟢正常 / 🔵执行中 / 🔴异常 |
| 最近执行 | 最近一次执行时间 | MM-DD HH:mm | 01-16 09:00 |
| 进度 | 执行中时显示进度 | 进度条 + 百分比 | ████░░░░ 65% |
| 启用开关 | 控制是否参与质检 | Switch组件 | 🔵开启 |
| 操作 | 操作菜单 | 下拉按钮 | [⋯] |

### 2.4 游戏渠道状态

| 状态 | 状态值 | 颜色标识 | 说明 |
|------|--------|----------|------|
| 执行中 | running | 🔵 蓝色 | 正在执行质检任务 |
| 正常 | normal | 🟢 绿色 | 等待下次执行 |
| 异常 | error | 🔴 红色 | 发生错误，需处理 |
| 已停止 | stopped | ⚪ 灰色 | 已手动停用 |

**状态展示规则：**
- 异常状态旁显示"查看"链接，点击可查看异常详情
- 执行中状态显示实时进度条
- 停用状态下，最近执行时间显示停用前最后一次

### 2.5 游戏渠道操作菜单

| 操作 | 说明 | 交互细节 |
|------|------|----------|
| 立即执行 | 仅执行该游戏渠道的质检 | 二次确认弹窗 |
| 查看历史 | 查看该游戏渠道的执行记录 | 弹出历史记录弹窗 |
| 导出结果 | 导出该游戏渠道的质检结果 | 弹出导出配置弹窗 |
| 查看异常 | 异常状态时显示 | 弹出异常详情弹窗 |
| 移除 | 从计划组中移除 | 二次确认弹窗 |

## 三、数据模型

### 3.1 游戏渠道项（GameChannelItem）

```typescript
interface GameChannelItem {
  id: string                    // 唯一标识
  planGroupId: string           // 所属计划组ID
  gameId: string                // 游戏ID
  gameName: string              // 游戏名称
  channel: string               // 渠道标识
  channelName: string           // 渠道名称
  enabled: boolean              // 是否启用
  status: 'running' | 'normal' | 'error' | 'stopped'
  lastExecutionTime?: string    // 最近执行时间
  currentProgress?: number      // 当前执行进度（0-100）
  errorInfo?: ErrorInfo         // 异常信息
  createdAt: string
  updatedAt: string
}
```

### 3.2 异常信息（ErrorInfo）

```typescript
interface ErrorInfo {
  type: 'dataMissing' | 'modelError' | 'resourceInsufficient' | 'progressAbnormal' | 'executionFailed'
  message: string       // 异常摘要
  detail?: string       // 异常详情
  occurredAt: string    // 发生时间
  resolvedAt?: string   // 解决时间
}
```

## 四、接口设计

### 4.1 添加游戏渠道

```
POST /api/plan-groups/:planGroupId/game-channels
```

**请求体**：
```json
{
  "gameId": "string",
  "channels": ["string"]  // 支持批量添加多个渠道
}
```

### 4.2 获取游戏渠道列表

```
GET /api/plan-groups/:planGroupId/game-channels
```

### 4.3 更新游戏渠道状态

```
PATCH /api/game-channels/:id/toggle
```

### 4.4 移除游戏渠道

```
DELETE /api/game-channels/:id
```

### 4.5 获取可用游戏列表

```
GET /api/games
```

### 4.6 获取游戏下的渠道列表

```
GET /api/games/:gameId/channels
```
