# P1-09 多视图展示

> 子需求ID：P1-09  
> 优先级：P1  
> 状态：待开发  
> 依赖：P0-01 计划组基础管理、P0-02 游戏渠道管理  
> 被依赖：无

---

## 一、需求概述

### 1.1 功能简介

支持多维度查看质检任务，提供计划组视图、按游戏视图、按渠道视图三种切换方式，便于不同角色的管理需求。

### 1.2 业务价值

- 满足不同角色的查看习惯
- 便于按游戏或渠道维度管理
- 快速定位特定游戏/渠道的质检状态

---

## 二、功能详情

### 2.1 视图切换

页面顶部提供三个Tab切换按钮：

| 视图 | 一级分组 | 二级分组 | 三级内容 |
|------|----------|----------|----------|
| 计划组视图 | 计划组 | - | 游戏渠道列表 |
| 按游戏视图 | 游戏 | 计划组 | 渠道列表 |
| 按渠道视图 | 渠道 | 计划组 | 游戏列表 |

### 2.2 计划组视图（默认）

以计划组为主维度展示，展开后显示该计划组下的所有游戏渠道。

**一级列表字段：**

| 字段 | 说明 |
|------|------|
| 计划组名称 | 计划组名称，支持展开/收起 |
| 状态 | 计划组状态标签 |
| 游戏渠道数 | 关联的游戏渠道数量 |
| 执行周期 | 每天/每周 + 时间 |
| 质检模式 | 会话标注/单轮标注 |
| 启用开关 | Switch组件 |
| 操作 | 更多操作菜单 |

**二级列表（展开后）：**

| 字段 | 说明 |
|------|------|
| 游戏 | 游戏名称 |
| 渠道 | 渠道名称 |
| 状态 | 执行状态 |
| 最近执行 | 最近执行时间 |
| 进度 | 执行中显示进度 |

### 2.3 按游戏视图

以游戏为主维度展示，展开后显示该游戏关联的所有计划组和渠道。

**一级列表字段：**

| 字段 | 说明 | 案例 |
|------|------|------|
| 游戏名称 | 游戏中文名，支持展开/收起 | 穿越火线 |
| 计划组数 | 关联的计划组数量 | 2个计划组 |
| 渠道数 | 关联的渠道数量 | 3个渠道 |
| 任务状态 | 汇总状态（有异常显示异常） | 🟢正常 / 🔴异常 |

**二级分组（按计划组）：**

| 字段 | 说明 |
|------|------|
| 计划组名称 | 计划组名称 |
| 执行周期 | 执行周期配置 |
| 状态 | 计划组状态 |

**三级列表（渠道）：**

| 字段 | 说明 |
|------|------|
| 渠道 | 渠道名称 |
| 状态 | 执行状态 |
| 最近执行 | 最近执行时间 |

### 2.4 按渠道视图

以渠道为主维度展示，展开后显示该渠道关联的所有计划组和游戏。

**一级列表字段：**

| 字段 | 说明 | 案例 |
|------|------|------|
| 渠道名称 | 渠道中文名，支持展开/收起 | 微信 |
| 计划组数 | 关联的计划组数量 | 3个计划组 |
| 游戏数 | 关联的游戏数量 | 5个游戏 |
| 任务状态 | 汇总状态 | 🟢正常 / 🔴异常 |

**二级分组（按计划组）：**

| 字段 | 说明 |
|------|------|
| 计划组名称 | 计划组名称 |
| 执行周期 | 执行周期配置 |
| 状态 | 计划组状态 |

**三级列表（游戏）：**

| 字段 | 说明 |
|------|------|
| 游戏 | 游戏名称 |
| 状态 | 执行状态 |
| 最近执行 | 最近执行时间 |

### 2.5 视图分组优化

- 游戏/渠道视图下，同一计划组的项目**合并展示**
- 展示计划组名称、状态、执行周期等关键信息
- 支持**展开/收起**查看详细列表
- 显示各级别的统计数量（如：3个计划组、5个任务）

### 2.6 统计信息展示

页面顶部显示汇总统计：

| 统计项 | 说明 | 案例 |
|--------|------|------|
| 计划组 | 计划组总数 | 计划组：5 |
| 游戏渠道 | 游戏渠道总数 | 游戏渠道：12 |
| 运行中 | 正在执行的任务数 | 运行中：2 |
| 异常 | 异常状态的数量 | 异常：1 |

## 三、数据模型

### 3.1 视图数据结构

**计划组视图数据：**
```typescript
interface PlanGroupViewData {
  planGroups: PlanGroupWithChannels[]
}

interface PlanGroupWithChannels extends PlanGroup {
  gameChannels: GameChannelItem[]
}
```

**游戏视图数据：**
```typescript
interface GameViewData {
  games: GameWithPlanGroups[]
}

interface GameWithPlanGroups {
  gameId: string
  gameName: string
  planGroupCount: number
  channelCount: number
  status: 'normal' | 'error'
  planGroups: {
    planGroup: PlanGroup
    channels: GameChannelItem[]
  }[]
}
```

**渠道视图数据：**
```typescript
interface ChannelViewData {
  channels: ChannelWithPlanGroups[]
}

interface ChannelWithPlanGroups {
  channel: string
  channelName: string
  planGroupCount: number
  gameCount: number
  status: 'normal' | 'error'
  planGroups: {
    planGroup: PlanGroup
    games: GameChannelItem[]
  }[]
}
```

## 四、接口设计

### 4.1 获取计划组视图数据

```
GET /api/views/plan-groups
```

### 4.2 获取游戏视图数据

```
GET /api/views/games
```

### 4.3 获取渠道视图数据

```
GET /api/views/channels
```

### 4.4 获取统计汇总

```
GET /api/views/summary
```

**响应**：
```json
{
  "planGroupCount": 5,
  "gameChannelCount": 12,
  "runningCount": 2,
  "errorCount": 1
}
```
