# P1-07 质检结果导出

> 子需求ID：P1-07  
> 优先级：P1  
> 状态：待开发  
> 依赖：P0-04 质检执行引擎  
> 被依赖：无

---

## 一、需求概述

### 1.1 功能简介

支持将质检结果导出为Excel文件，便于离线分析和汇报。支持按时间范围、游戏渠道筛选导出内容。

### 1.2 业务价值

- 支持离线数据分析
- 便于生成质检报告
- 方便与其他系统对接

---

## 二、功能详情

### 2.1 导出入口

| 入口位置 | 说明 |
|----------|------|
| 计划组操作菜单 | "导出质检结果" - 导出该计划组所有游戏渠道的结果 |
| 游戏渠道操作菜单 | "导出质检结果" - 导出该游戏渠道的结果 |
| 历史记录详情弹窗 | "导出本次结果" - 导出单次执行的结果 |

### 2.2 导出配置弹窗

**弹窗字段：**

| 配置项 | 字段名 | 类型 | 必填 | 默认值 | 说明 |
|--------|--------|------|------|--------|------|
| 时间范围 | dateRange | 日期范围选择器 | ✅ | 最近7天 | 选择质检执行的时间范围，最大跨度30天 |
| 导出范围 | exportScope | 下拉多选 | ✅ | 全部游戏渠道 | 全部游戏渠道 / 指定游戏渠道（支持多选） |
| 导出内容 | exportContent | 多选复选框 | ✅ | 全选 | 基础信息 / 质检详情 / 异常记录 |

### 2.3 导出文件说明

| 项目 | 说明 | 示例 |
|------|------|------|
| 格式 | Excel文件 | .xlsx |
| 文件名 | {计划组名称}_质检结果_{开始日期}_{结束日期} | 甄选日常质检计划_质检结果_20260110_20260116.xlsx |
| 导出限制 | 单次最多导出10000条记录，超出时提示分批导出 | - |
| 大数据处理 | 数据量>5000条时，后台异步导出，完成后通知用户下载 | - |

### 2.4 导出Excel字段说明

**Sheet1：质检明细**

| 字段名称 | 说明 | 展示要求 | 案例 |
|----------|------|----------|------|
| 会话ID | 会话唯一标识 | 文本格式，保持原始ID | cfm_20260115_093000_001 |
| 游戏名称 | 游戏中文名 | 文本 | 穿越火线 |
| 渠道名称 | 渠道中文名 | 文本 | 微信 |
| 质检时间 | 质检执行时间 | YYYY-MM-DD HH:mm:ss | 2026-01-15 09:30:00 |
| 质检结果 | 质检结论 | 文本：优秀/合格/不合格/风险 | 合格 |
| 质检评分 | 综合评分 | 数字，保留1位小数 | 85.5 |
| 问题数量 | 发现的问题项数量 | 数字 | 2 |
| 问题详情 | 具体问题描述 | 多个问题用换行分隔 | 1.[#11041]服务主动性-推荐内容与用户咨询无关 |
| 对话内容 | 完整对话记录 | 保持时间戳和角色标识 | 2026-01-15 09:28:00 玩家：xxx... |

**Sheet2：执行统计（可选）**

| 字段名称 | 说明 |
|----------|------|
| 执行时间 | 质检执行开始时间 |
| 游戏渠道 | 游戏-渠道 |
| 总任务数 | 本次质检数据条数 |
| 完成数 | 成功完成条数 |
| 失败数 | 失败条数 |
| 缓存命中 | 复用结论条数 |
| 结果分布 | 优秀/合格/不合格/风险数量 |

### 2.5 交互说明

- 点击"导出"按钮后，若数据量≤5000条，直接下载文件
- 若数据量>5000条，显示提示："数据量较大，已提交后台处理，完成后将通过消息通知您下载"
- 导出过程中按钮显示loading状态，禁止重复点击
- 导出完成后显示成功提示

## 三、数据模型

### 3.1 导出任务（ExportTask）

```typescript
interface ExportTask {
  id: string
  planGroupId: string
  dateRange: {
    startDate: string
    endDate: string
  }
  exportScope: string[]         // 游戏渠道ID列表
  exportContent: ('basic' | 'detail' | 'error')[]
  status: 'pending' | 'processing' | 'completed' | 'failed'
  progress: number              // 0-100
  fileUrl?: string              // 下载链接
  recordCount: number           // 记录数
  createdAt: string
  completedAt?: string
  errorMessage?: string
}
```

### 3.2 导出记录（ExportRecord）

```typescript
interface ExportRecord {
  sessionId: string
  gameName: string
  channelName: string
  inspectionTime: string
  result: 'excellent' | 'qualified' | 'unqualified' | 'risk'
  score?: number
  issueCount: number
  issueDetails: string
  conversationContent: string
}
```

## 四、接口设计

### 4.1 创建导出任务

```
POST /api/export-tasks
```

**请求体**：
```json
{
  "planGroupId": "string",
  "dateRange": {
    "startDate": "2026-01-10",
    "endDate": "2026-01-16"
  },
  "exportScope": ["gameChannel1", "gameChannel2"],
  "exportContent": ["basic", "detail"]
}
```

**响应**：
```json
{
  "taskId": "string",
  "estimatedRecords": 3500,
  "isAsync": false
}
```

### 4.2 获取导出任务状态

```
GET /api/export-tasks/:taskId
```

### 4.3 下载导出文件

```
GET /api/export-tasks/:taskId/download
```

### 4.4 获取导出历史

```
GET /api/export-tasks
```
