# 操作指南：从自动质检计划到人工标注全流程

> 版本：v1.0  
> 更新日期：2026-03-26  
> 适用角色：产品/运营（配置）、标注员（执行）

---

## 整体流程概览

```
创建自动质检计划 → 质检自动执行 → 创建质检任务 → 人工标注
```

---

## 一、创建自动质检计划（人工配置）

### Step 1：新建计划组

**入口**：自动质检页面右上角 → 点击「新建计划组」

配置弹窗分为以下六个区域：

---

#### 1.1 基本信息

| 配置项 | 是否必填 | 说明 |
|--------|----------|------|
| 计划组名称 | ✅ | 唯一标识，最多50字，如：甄选日常质检计划 |
| 描述 | ❌ | 补充说明，最多200字 |
| 关联质检规则 | ✅ | 选择已发布的质检规则版本 |
| 启用状态 | ✅ | 默认开启 |

---

#### 1.2 执行计划配置

| 配置项 | 是否必填 | 说明 |
|--------|----------|------|
| 执行周期 | ✅ | 每天 / 每周（指定周几）/ 自定义 Cron |
| 执行时间 | ✅ | 精确到分钟，如 09:00 |
| 质检模式 | ✅ | 单轮标注（一问一答）/ 会话标注（整场 Session）|
| 质检数据范围 | ✅ | T-1 日 / T-2 日 / 自定义 |

---

#### 1.3 抽样配置

| 配置项 | 是否必填 | 说明 |
|--------|----------|------|
| 抽样方式 | ✅ | 随机抽样 / 最新优先 / 全量 |
| 抽样数量 | ✅ | 1～10000 条，默认 500 条 |
| 抽样范围 | ✅ | 每个游戏独立抽取该数量 / 所有游戏合计抽取该数量 |

---

#### 1.4 数据过滤规则（选填）

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 过滤纯 Bot 会话 | 开启 | 仅 Bot 推送、用户未回复的会话直接跳过 |
| 过滤用户未回复 | 开启 | 用户无任何回复的会话直接跳过 |
| 黑名单关键词 | 无 | 命中关键词的会话/单轮跳过，如："测试"、"test" |
| 最小消息数 | 1 | 低于此值则过滤 |
| 最大消息数 | 不限 | 高于此值则过滤 |

> **说明**：多个过滤条件为 AND 关系；过滤在抽样之前执行，被过滤数据不消耗 Token。

---

#### 1.5 监控配置（选填）

| 监控项 | 默认阈值 | 说明 |
|--------|----------|------|
| 缺数据监控 | 连续 3 次 | 连续 N 次无数据时告警 |
| 模型报错监控 | 错误率 > 10% | LLM 报错、Token 超限、API 超时 |
| 资源不足监控 | 积压 > 1000 条 | 任务队列积压严重 |
| 进度异常监控 | 预计超时 2 小时 | 执行时间异常过长 |

---

#### 1.6 告警配置（选填）

| 配置项 | 说明 |
|--------|------|
| 企业微信机器人 | 填写 Webhook 地址，异常时推送群消息 |
| 邮件通知 | 开启后发送邮件，收件人格式：`rtx名称`（自动生成 @tencent.com 邮箱）|

---

### Step 2：添加游戏渠道

计划组创建完成后，进入计划组详情，添加游戏 + 渠道组合（如：穿越火线 + 微信）。

---

### Step 3：等待自动执行 / 手动立即执行

| 触发方式 | 操作 |
|----------|------|
| 定时触发 | 到达配置时间后系统自动触发，无需操作 |
| 手动触发 | 计划组操作菜单 → 「立即执行」→ 二次确认 → 任务加入队列 |

---

## 二、创建质检任务（人工配置，共 5 步）

**入口**：任务中心 → 「新建任务」

---

### Step 1：任务基本信息设置

| 配置项 | 是否必填 | 说明 |
|--------|----------|------|
| 任务名称 | ✅ | — |
| 标注数据类型 | ✅ | 对话 / 文本块 / 图片 |
| 任务描述 | ❌ | — |

---

### Step 2：标注数据来源配置

选择数据来源方式：

#### 方式 A：线上日志拉取

| 配置项 | 是否必填 | 说明 |
|--------|----------|------|
| 目标拉取 DB | ✅ | 如：全量消息表、UO 灰度消息表 |
| Bot ID | ✅ | 指定质检的 Bot |
| 回复类型 | ❌ | MQA / Agent / 人工，多选 |
| 风险等级 | ❌ | 高 / 中 / 低 / 无，多选 |
| 数据量 | ✅ | 拉取条数 |
| 时间范围（单次任务）| ✅ | 指定开始和结束日期 |
| 执行周期（周期任务）| ✅ | 指定起止日期 + 每周几执行 + 执行时间 |
| 抽样配置 | ❌ | 开启后选择随机/系统抽样，配置数量 |
| 过滤条件 | ❌ | 关键词过滤、无回复过滤、纯 Bot 过滤等 |

#### 方式 B：手动导入数据

- 上传数据文件，等待上传成功后方可进入下一步

---

### Step 3：标注项配置

- 选择标注类型（可使用任务模板快速配置）
- **至少选择 1 个标注项**，方可进入下一步

---

### Step 4：任务分配

**第一步：选择标注员**（至少选择 1 人）

**第二步：根据人数决定分配方式**

#### 单人场景

仅分配 1 名标注员，系统自动全量分配，该标注员标注所有数据。

#### 多人场景：选择标注方式

| 标注方式 | 说明 | 适用场景 |
|----------|------|----------|
| **交叉标注** | 多人标注同一批数据 | 质量要求高，需多人校验 |
| **分散标注** | 不同人瓜分数据，各自标注不同部分 | 数据量大，追求效率 |

**交叉标注追加配置：**

| 配置项 | 说明 |
|--------|------|
| 最少标注次数 | 每条数据至少被标注 N 次（不超过标注员人数）；不填则每人全量标注 |
| 统计方式 | 平均值 / 中位数，用于聚合多人标注结果 |

**分散标注追加配置（数据分配规则）：**

| 分配方式 | 说明 |
|----------|------|
| 平均分配 | 系统自动将数据均分给各标注员 |
| 定额分配 | 手动为每位标注员设置配额数量 |

---

### Step 5：时限配置

| 配置项 | 说明 |
|--------|------|
| 绝对时间 | 指定截止日期 |
| 相对时间 | 从任务发布起，N 天 N 小时后截止 |

配置完成 → 点击「创建任务」

---

## 三、人工标注步骤

### 3.1 单人标注场景

**流程：**

1. 标注员进入任务中心，找到分配给自己的任务
2. 点击任务 → 进入标注工作台
3. 逐条查看对话内容，按标注项要求进行标注
4. 每条完成后提交，系统自动跳转下一条
5. 全部完成后任务状态变为「已完成」

> **数据分配**：全量数据由该标注员独立完成，无需聚合。

---

### 3.2 多人标注场景

#### 场景 A：交叉标注（多人标注同一批数据）

**流程：**

1. 系统将同一批数据分发给所有参与标注员
2. 各标注员独立进入工作台完成标注，互不可见对方结果
3. 所有人完成（或达到最少标注次数要求）后，系统自动聚合
4. 聚合方式按配置执行：
   - **平均值**：各标注员评分取平均作为最终结论
   - **中位数**：取中位数作为最终结论
5. 管理员可在任务详情中查看各人标注结果及最终聚合结果

> **适用场景**：质量要求高、需要多人校验减少主观偏差的标注任务

---

#### 场景 B：分散标注（不同人标注不同部分数据）

**流程：**

1. 系统按分配规则将数据切分后下发给各标注员
   - 平均分配：系统自动均分
   - 定额分配：各标注员按配额接收对应数量的数据
2. 各标注员进入工作台，只看到分配给自己的数据
3. 独立完成标注后提交
4. 所有标注员完成后，任务整体状态变为「已完成」

> **适用场景**：数据量大、需要多人协作高效完成的标注任务

---

## 四、全流程一览

| 阶段 | 操作人 | 关键步骤 |
|------|--------|----------|
| 创建自动质检计划 | 产品/运营 | 新建计划组 → 配置执行周期/抽样/过滤/监控告警 → 添加游戏渠道 |
| 质检自动执行 | 系统 | 定时/手动触发 → 数据清洗抽样 → LLM 质检 → 记录结论 |
| 创建质检任务 | 产品/运营 | 5 步配置：基本信息 → 数据来源 → 标注项 → 分配方式 → 时限 |
| 人工标注（单人）| 标注员 | 全量独立标注 → 逐条提交 |
| 人工标注（多人-交叉）| 多位标注员 | 各自独立标注同一批数据 → 系统按平均值/中位数聚合结果 |
| 人工标注（多人-分散）| 多位标注员 | 各自标注分配到的数据分片 → 汇总完成 |
